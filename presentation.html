Topic 03 • Core Innovation

AI Approach: Deterministic Multi-Agent Cognitive Pipeline

Why Generic LLMs Fail at Chip Design
  • Hallucinates Software Libraries: Suggests Python/C syntax illegal in synthesizable SystemVerilog.
  • Waveform Blindness: Cannot correlate nanosecond signal transitions or clock edges.
  • Ignores Fan-In Topology: Unaware of flip-flop logic cones, CDC crossings, or 4-state simulation (X/Z).
  • No Execution Feedback: Output is unchecked; cannot tell if code compiles or breaks existing tests.
The VeriSight Multi-Agent Solution
  • 9 Deterministic Decision Rules: Eliminates hallucinations via strict logical categorization.
  • Static AST X-Tracer: Recursively traces unknown logic states backwards along clock trees to origin flip-flops.
  • Multi-Modal Temporal Slicing: Extracts narrow +/-20 cycle VCD windows around assertion failures.
  • Isolated Sandbox Validation: Automatically re-compiles and executes regression tests before sign-off.

Topic 05 (Cont.) • Deterministic Grounding

The 9 Formal Decision Rules & X-Tracer Engine

The 9 Formal Decision Rules
RuleFault CategoryDiagnostic Action
Rule 1Scoreboard MismatchDistinguishes golden reference bugs from RTL math defects.
Rule 2X-PropagationTraces unknown logic state (X) back to uninitialized flop.
Rule 3Protocol ViolationFlags SVA handshake violations (request/grant latency).
Rule 4Timing / GlitchDetects setup/hold race conditions & missing CDC flops.
Rule 5Driver HangIdentifies un-dropped UVM objections stalling phase finish.
Rule 6FIFO / Buffer HazardDetects read-on-empty underflow or full flag calculation bugs.
Rule 7Structural LintIdentifies unintended combinational latches or truncated buses.
X-Tracer Backward Cone Traversal

Solves the notorious "X-state mystery" in 4-state simulation:

  1. Parses & elaborates the RTL into a real AST using pyslang (Slang SystemVerilog frontend).
  2. Statically flags sequential registers written but not assigned in their reset branch (candidate X origins).
  3. Optionally, when a VCD is supplied, the external x-tracer tool traverses the gate-level fan-in cone back from cycle T to the origin flop.
  4. Static source analysis finds candidates; the simulation layer confirms the runtime propagation path.
